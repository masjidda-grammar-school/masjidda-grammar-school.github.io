মছজিদ্দা গ্রামার স্কুল — Multi-page website

সব HTML ফাইল একই GitHub repository root-এ আপলোড করুন। index.html হোম পেজ। assets নামে আগের ছবির ফোল্ডারটি একই জায়গায় রাখতে হবে।

পেজসমূহ: index.html, about.html, academics.html, admission.html, parents.html, activities.html, resources.html, gallery.html, contact.html

বিদ্যমান মেনু ও সাবমেনুর নাম, ক্রম ও কাঠামো অপরিবর্তিত রাখা হয়েছে। হোম পেজে বিস্তারিত অনুচ্ছেদ বাদ দিয়ে ছবি, শিরোনাম ও বিস্তারিত বাটন রাখা হয়েছে। বিস্তারিত তথ্য আলাদা পেজে রয়েছে।
